# Image slots

The layout currently uses named image placeholders and a CSS material-study composition. It does not include generated images, admin-uploaded images, or images from the reference attachments.

| Placement | Suggested file | Shape | Notes |
|---|---|---:|---|
| Home hero | `public/assets/images/home-hero.webp` | 4:5 | Approved HDC print-work or material photograph |
| Product detail | `public/assets/images/products/{slug}.webp` | 4:5 | Use an actual representative product or surface |
| Service feature | `public/assets/images/services/{slug}.webp` | 3:2 | Add only when a genuine HDC reference exists |

Keep source image files outside public until approved. Use descriptive filenames, optimized WebP/AVIF derivatives, and meaningful alt text for informative images. Decorative material imagery should use empty alt text. Preserve the grid and crop targets when replacing the placeholders.
